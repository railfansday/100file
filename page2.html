November Patch Tuesday: An Overflowing Cornucopia of CVEs

📅 Nov 10, 2026  |  Category: Technology  |  Read Source →

Microsoft serves up an actively exploited Outlook zero-day, and a wave of critical Exchange, SharePoint, Windows Search, and LDAP bugs that exhausted defenders need to prioritize fast.

November offers up a veritable Patch Tuesday feast of vulnerabilities that are more likely to be exploited. In its second four-digit Patch Tuesday release in a row, Microsoft today addressed 1,093 security vulnerabilities, with 63 rated critical, and one zero-day in the mix (CVE-2026-124194, CVSS 6.5) that Microsoft confirmed is under active exploit.

"Most security teams haven’t quite recovered from the last month of bumper-to-bumper critical vulnerabilities, emergency patches, and '2shell'-branded everything, and we're yet again at another Patch Tuesday," says Jake Knott, head of threat intelligence at Watchtowr.

"Teams are really starting to feel the strain of working out what actually matters when there is fire after fire every day demanding immediate attention," he adds. "Our advice hasn't changed … start with what you actually have exposed to the Internet, then what's already being exploited in the wild, and only then everything else. Before going into panic mode, check whether you even use the vulnerable component, or meet the prerequisites for exploitation."

Related:OnlyFans Copyright Takedowns Expose Compromised Websites

To that end, security teams should prioritize CVE-2026-124194, and not just because attackers are already targeting it. It's a spoofing vulnerability in Outlook that may not allow code execution, hence its moderate severity rating, but could allow the disclosure of an account’s NTLMv2 hash — and in turn, the target's login.

"To exploit it, an attacker sends a target a malicious Office file and convinces them to open it," explained Satnam Narang, senior staff research engineer at Tenable, in his monthly Patch Tuesday commentary. "If the attack succeeds, the attacker captures the victim's NT LAN Manager v2 (NTLMv2) hash, a value derived from their Windows password. The attacker may be able to relay it to other systems to sign in as the user, or crack it to recover the password."

Security teams should also prioritize a pair of critical remote code execution (RCE) vulnerabilities, in Exchange and SharePoint, respectively, that each open targets to any attacker with a low-privilege login.

The first, in Exchange Server (CVE-2026-118207, CVSS 8.8), "belongs in this week's emergency window for every Exchange Server Subscription Edition server you run," Automox researchers warned in their monthly Patch Tuesday bulletin, and "all an attacker needs to start is a low-level login."

It's an improper input validation that could allow an authenticated attacker with low-level access to send the server a specially crafted request and run code with no user interaction.

"Code on an Exchange server reaches every mailbox it hosts," warned Automox researchers. "And Exchange usually holds broad rights in Active Directory, so the mailboxes are just the start."

Meanwhile, an important-rated flaw (CVE-2026-120002, CVSS 9.9) in SharePoint Server is an elevation of privilege vulnerability that needs quick addressing, according to Automox.

"The flaw is incorrect authorization," the researchers noted. "That 9.9 comes from a changed scope: a successful attack reaches past the vulnerable SharePoint component itself. An attacker who already holds a low-privileged account sends requests over the network and elevates their privileges, with no user interaction required."

Another critical RCE to watch out for, according to Automox, is CVE-2026-110043 (CVSS 8.8/10), a one-click heap-based buffer overflow in Outlook that uses the Preview Pane as an attack vector. A target must select a weaponized email so it displays in the Preview Pane for it to trigger the attacker's code, which runs with that user's permissions.

"Patch internet-facing Exchange and SharePoint servers, and book the Exchange restart now," the Automox researchers advised. "Push the Office update this week, then check the installed build, because a fully patched Windows dashboard says nothing about Office. Rank by score and assessment, not label."

Dustin Childs, head of threat awareness at the Zero-Day Initiative (ZDI), also identified a Windows Search RCE (CVE-2026-116928, CVSS 9.8) as needing immediate attention.

"We start with Windows Search, which is reached through Exchange Server," he said in his November Patch Tuesday blog post, where he also listed 30 potentially wormable CVEs to patch quickly. "This bug allows an unauthenticated attacker to send an email with a specially crafted attachment that triggers the bug when the server automatically indexes it. The recipient never opens anything. It is a zero-click code execution bug on a high-value target. It’s also a CVSS 9.8 and clearly more severe than any of the nine patches Exchange receives this month."

And finally, Childs pointed to CVE-2026-119958, an RCE bug in Windows Lightweight Directory Access Protocol (LDAP).

"This patch addresses a bug that allows an unauthenticated attacker to exploit an out-of-bounds (OOB) write (CWE-787) by sending crafted LDAP calls over the network, with no user interaction," he warned. "Since it runs code in the LDAP service context, it could be quite destructive, especially on Domain Controllers. Test and deploy this one quickly."

Childs also recommended testing and deploying patches for the wormable bugs quickly, especially for network-facing services like DNS, DHCP, LDAP, and Exchange.

White the cornucopia of CVE this month, especially on the heels of the record October Patch Tuesday, may feel overwhelming, security teams should stick to best practices and not get overwhelmed, advises Tyler Reguly, associate director of security R&D at Fortra.

"I don't know about everyone else, but I'm tired," he said via email, adding that he believes that, eventually, AI will finish turning up old bugs and teams can once again look forward to smaller Patch Tuesday releases. "I can only imagine that if I’m tired, admins and operations teams everywhere are also tired. I believe that we will make it through to the other side, if we prioritize updates and focus on what really matters. The noise is coming at us from all sides, and we need to cut through it and figure out what really matters to the business."

Streaming activity contributed 32,000 units of the sum (a figure representing 34.2 million official on-demand streams of the album’s songs), traditional album sums provided 22,000 units and 1,000 units were from track-equivalent album units. Gochman Collection Builds a Home for Native Art in Westchester

📅 Nov 10, 2026  |  Category: Business  |  Read Source →

The private collection opened its Branchline location in Katonah as a way to bring Native art into public view, though questions linger about its engagement with the local Lenape community.

KATONAH, NY — In 1680, English colonists bought the land that would become Bedford, New York, from a Munsee Lenape sachem named Katonah, meaning “great hill.” Today, his name belongs to a Westchester village that is now home to Branchline, the Gochman Family Collection’s (GFC) new gallery and studio space, which opened to the public on November 6 with Line Break, an exhibition of works drawn primarily from its holdings of contemporary Native American art.

Since its founding in 2021, GFC has collected over 800 works with support from Native and non-Native gallerists, artists, and curators alike, including Creative Director and Curator Rachel Martin (Tlingít), curator and Hyperallergic contributor Shándíín Brown (Diné), and Director Laura Phipps, who also serves as Branchline’s director. Designed by Elizabeth Roberts Architects, the new space occupies two historic storefronts steps from Katonah’s Metro-North station, with free-admission galleries, skylit artist studios, a community ceramics studio, and apartments for invited artists.

Branchline makes a public home for what has essentially been a lending operation: According to GFC, more than 260 of its works have appeared in over 100 exhibitions at institutions including the Metropolitan Museum of Art, the Whitney Museum of American Art, and The Broad, and it charges no loan fees. That model speaks to a known problem with private collecting, explained Joseph Pierce (Cherokee), professor and founding director of the Native American and Indigenous Studies Initiative at Stony Brook University. “Just because you collect something doesn’t mean you’re going to show it,” Pierce told Hyperallergic. “The risk is that it doesn’t circulate.”

The 10 Most Intense Movie Scenes of All Time, Ranked

📅 Nov 10, 2026  |  Category: Entertainment  |  Read Source →

Looking over some of the most intense movie scenes of all time is also going to reveal a bunch of movies that themselves can be counted as the most intense of all time. Overlap’s inevitable, but the focus below will be on those individual scenes. Sure, a scene can be long, taking up 10 to 20 percent of a movie’s runtime in some cases, or if it’s suspenseful for a shorter amount of time, maybe it’s an especially harrowing two to three minutes.

Also, talking about specific scenes will mean spoilers can be found below, but not every scene here necessarily takes place near a film’s conclusion. And for one more “also,” these movies have all been out for at least a few years, and most are quite well-known, so you're unlikely to have too much genuinely spoiled here, if you're interested enough in movies overall to read (or skim) a ranking like this.

Since 2027 is less than two months away, at the time of writing, Children of Men might well be an even more stomach-churning watch nowadays than it might've been back in 2006. Most dystopian movies are intense in one way or another, for hopefully obvious reasons, but the bleak future (which isn't a future for much longer) of Children of Men feels especially so.

The first scene is shocking, as are two set pieces that involve a car (one of them in the car, and one involving a car that doesn’t start), yet the final sequence, which sees the surviving characters (not too many) caught up in an all-out war zone, is the most full-on in Children of Men. It contains the most elaborate of the movie’s long takes, and it does an uncomfortably good job at making you feel like you're caught up in all the horror and bloodshed yourself.

There was a time when the shower scene in Psycho might've been genuinely surprising, but nowadays, you know, it’s the shower scene from Psycho. It comes before the halfway point of the movie, and it features the only character who’s been in the entire movie, scene by scene, up until that point. And out of nowhere, she’s murdered in a way that was very shocking by the standards of the early 1960s.

It’s a real shock to the system, or would've been before it became legendary, and so for all that, this scene’s well and truly earned its reputation.

It’s about as famous as thriller movie scenes get, and it played a part in rewriting the rules of what you could and couldn’t do early on in a movie. It’d be shocking enough to have the shower scene happen at the end, but when it happens where it does here, it’s like, “Wow, there’s an hour left, and now literally anything can happen… and actually, what even can happen?” It’s a real shock to the system, or would've been before it became legendary, and so for all that, this scene’s well and truly earned its reputation as an all-time great moment in cinema history.

Alfred Hitchcock got a shout-out here by highlighting Psycho, and then David Fincher, who’s also got a knack for directing suspenseful and effortlessly intense movies, is going to be mentioned shortly. In similar territory is Brian De Palma, and it feels necessary to highlight at least one scene he’s done as being especially intense, so of all the candidates (often finales; see Carrie and Scarface), here’s the big shootout in The Untouchables.

Well, it’s kind of big. The gunfight itself doesn't technically last too long, but The Untouchables spends an agonizingly long time building it all up, and then the use of slow motion during the build-up and when the shooting itself starts also draws the scene out in the best of ways. It’s such an expertly done set piece, and even if De Palma might have some movies that are darker and more consistently tense than The Untouchables, it’s this single scene that best demonstrates his knack for crafting cinematic suspense.

Make no mistake: pretty much the entirety of Zodiac is tense, and then when it’s not tense, it’s more disquieting and despairing. The search for the Zodiac Killer is at the core of the story, unsurprisingly, and most of the tense parts play out when the killer himself is at large, with the more subtly uneasy parts being found in the back half, when the chances of actually finding the killer seem to dissipate further scene by scene.

The terror does come back in full force, though, with the infamous basement scene in Zodiac, which happens closer to the end and involves Robert Graysmith possibly encountering the killer, but the not knowing – and the darkness of the sequence visually – bring the film the closest it gets to outright horror territory. It’s far from the only memorable scene in Zodiac, of course, but it does leave the biggest impact.

The scene you probably remember as being the opening one, even if Saving Private Ryan does start decades after the end of World War II before flashing back, it’s that famous extended sequence depicting the D-Day Landing at Omaha Beach. Guess it is chronologically the first scene that takes place in Saving Private Ryan, and it does have such an impact that it sticking in one’s mind over the actual opening scene is understandable.

There is also a large-scale battle sequence near the end of Saving Private Ryan, and that’s no slouch in terms of showing some truly visceral combat either. However, it's this opening sequence that proves most startling, coming earlier in the film, and it’s also a depiction of an actual battle, so it has that extra sense of dread and terror to it (the final battle is fictionalized, though it does aim to convey World War II-era combat nonetheless).

There are pictures here. You need pictures in an article, apparently. There was an effort made with all the other movies to source relevant pictures (you know, not just showing any moment from Saving Private Ryan or Psycho, but screenshots that convey the scene in question and the relevant intensity). With The Silence of the Lambs, though, the notably tense sequence – or at least the most intense part of that sequence – is memorably very dark, and it’s harder to make things out when it’s not in motion.

It involves Clarice Starling finally confronting Buffalo Bill, and eventually thwarting him, but not until after he switches off all the lights and stalks her around his already creepy house/basement while wearing night-vision goggles. It’s perhaps the part when The Silence of the Lambs most feels like a horror movie, though any big scene with Hannibal Lecter is, quite naturally, also frightening (an honorable mention should go out to his big escape sequence).

You do know this one is coming at all points, and sure, there is even some relief when it happens, just because 127 Hours so perfectly captures – and makes you feel – the utterly nightmarish situation its central character is in throughout. He is hiking without sufficient company and safety equipment, and ends up trapped when a boulder falls on his arm, crushing it and then ultimately not being movable.

So, after several days, he makes the decision to amputate his arm with the very few pieces of equipment he has nearby, and it is what saves his life, sure, but it does also prove nauseating to watch because nothing is shied away from. It’s one of the most painful-to-watch scenes in relatively recent memory, yet it has to be, and there is an understandably great sense of relief alongside the absolute nausea you'll feel witnessing it all.

Jaws is another Steven Spielberg movie that, like Saving Private Ryan, technically begins near or on a beach, and also in a manner that proves surprising and famously intense. That first shark attack scene is monumental, as are a bunch of the sequences that follow throughout the first hour or so of Jaws, though the final act is where the movie obviously crescendos, and if you want to call it the “final showdown,” then that’s it. That’s what’s going here.

You’ve got a whole movie of things not really letting up, and it’s still all quite patiently done, not to mention in a manner that makes being truly invested in that climax inevitable. Jaws is – and forever will be – the best movie about three guys who have to go out to sea and kill a shark, and this extended climax is a big reason why.

Everything in Inglourious Basterds is pretty great, and it’s also a film that has a handful of standout scenes that all manage to feel incredibly tense, but usually in different ways, so there’s no real repetition here. It’s longer than a fair few Quentin Tarantino movies, albeit paced in a way that really makes it all fly by, and all the big scenes help immensely in that regard.

That does also make highlighting one over all the others tough, but here, the one that’s going to be singled out is the tavern sequence. All the other show-stopping scenes are perfect and 10/10-worthy, with this one, like, being an 11/10 scene. Movies don’t get much more nerve-wracking than this, and it’s a shame you can only ever see something for the first time just the once, since being able to experience a scene this perfectly surprising again would be wonderful.

There’s no shark here, but Whiplash does a similar thing to Jaws in terms of having suspense and unease pretty much right from the start, and then having those feelings become more intense as things progress. You're not given a lot of time to breathe, and the dynamic between a dedicated student and a tyrannical instructor gets impossibly uncomfortable, not to mention psychologically harrowing, continually reaching new heights… or lows?

Anyway, that does result in the climax being the biggest and most jaw-dropping sequence in the movie. Whiplash also twists the knife after it’s over, since the movie leaves you hanging in terms of the implications of the eventual moment of triumph, or tragedy. Or it could be a bit of both. It’s hard to know. You'll never know. So you're on the edge of your seat for the final 10 to 15 minutes of Whiplash, and then you continually feel queasy for the next 10 to 15 years after Whiplash came out, whenever you think about it and its ending. That is undoubtedly impressive stuff for a movie’s ending to do.

It was stuck in “Shuffle” mode, and had developed a couple of other quirks, but it worked well enough. It defended me valiantly against earworms for the remainder of my thru-hike.

I headed north out of town along Kennedy Street. During the 1.5 mile road-walk, three pickup trucks drove past. Each truck was outfitted with several kennels, and each kennel contained an excited, baying hound. As the noise faded into the distance, I reached the trailhead, headed east, and silence descended. With some background music, of course.

That afternoon, I met hikers Linda and Wendy, who were heading west. They were piecing together the entire IAT by parking a vehicle at each of two trailheads, and hiking from one to the next. I met them again at Wood Lake County Park campground, and they were very hospitable. They let me share their campsite, and that evening, Wendy cooked Gnocchi, Pesto, and Chicken of the Woods (mushrooms that she’d picked that day).

In the morning, after only two miles, I saw the three pickup trucks again, empty this time. They were parked at my first trailhead of the day, and I could hear the hounds’ sounds coming from the direction I needed to go. Whether they were training or hunting, I wasn’t sure. Randomly, my MP3 player chose that moment to select “Dueling Banjos”.

Not really. But it would have been appropriate.

I decided to walk the road for a few miles, heading south. Again, the noise faded into the distance.

Compared to western states, Wisconsin sounds different. This was day 17, and I was still noticing birdsongs I hadn’t heard before. The R2-D2 bird, for example. I’d recently discovered that the creatures snorting at me from afar were White-tailed bucks, who apparently have an excellent sense of smell. Mule deer out west have never snorted at me.

In camp, at sunset, three wolf-packs exchanged howls several miles away. It was the only time on the Ice Age Trail that I heard wolves, so they’re probably no more common in the midwest than the west.

The next day, I hiked north along the west bank of the Wisconsin River, then south along the other side. The Grandfather Falls dam and hydropower plant were interesting, but the subsequent out-and-back was not, at least according to FarOut commenters. I know the IAT is a work-in-progress, but I believe a three mile round-trip with no pay-off is optional for thru-hikers. I skipped it, and immediately started a 10 mile road-walk.

I dodged most of a heavy rain shower by sheltering in the pavilion at Tug Lake County Park, and was dry by the time I reached my campsite, which was, in this case, a shelter. It was my first ever night in one – cozy, even if the neighbors were noisy. I now know that the birds at Dog Lake that night were Sandhill cranes.

The next night, my neighbors were remarkably quiet. At the campsite on the other side of Chain Lake, about 300 yards away, were 16 teenagers and two camp counselors from Milwaukee. It sounded like everyone was fast asleep as soon as the sun went down.

I only hitched once on the IAT, going to Rhinelander. I stayed the night, and tried hitching back mid-morning. There were roadworks on the edge of town, which might be why state route 17 wasn’t very busy. An hour later, I had no takers. I tried Uber, also unsuccessfully, then called a cab. Five minutes later, they picked me up. I was back on trail at midday, and reached a suitable place to camp about five o’clock.

Actually, suitable is an exaggeration. I chose a flat patch of grass beside a five-way intersection of overgrown, disused dirt roads. I wouldn’t have camped there if this had been Grizzly territory.

As expected, the intersection was busy that night, but each disturbance didn’t keep me awake for long. Then, at 1:15 AM, something started growling at me, and I was wide awake in an instant, heart thumping.

I’ve been growled at by dogs and coyotes, and grumbled at by porcupines and raccoons. This sound wasn’t canine, and the animal making it didn’t sound small. In my imagination, the creature was bear-sized.

I used my outside voice, but there was no reaction. I unzipped my tent door and shone my flashlight around. Still no movement. I couldn’t see the animal because it was on the other side of my tent. Periodically, for about 15 minutes, it uttered a low, rumbling growl lasting several seconds. Each time, I replied with a few words.

Then, at last, it padded quietly away. I lay awake for 45 minutes while the adrenaline subsided. In the morning, when I had cell service, I researched my nocturnal visitor, and suddenly everything made sense. Wisconsin is the Badger State.

Fast-forward a few hours, and I had a silent night. Wholly unexciting night. All was calm, all was quite… normal. The morning was a bit chilly, but that’s hardly worth mentioning.

In the afternoon, near the tiny community of Polar, I arrived at my chosen campsite on the shore of Mueller Lake. On the water, I could hear a couple of speedboats, their stereos, and the shrieks of people enjoying themselves. The boaters soon went home, and for a time, it was peaceful.

Then the residents of the lakefront house 400 feet away fired up their megawatt outdoor sound system. For the next three hours, I was treated to a Spotify 70’s selection with commercial breaks. Full-size headphones with noise cancelling would have been useful. Fortunately, the loudspeakers fell silent just before sunset.

So, if someone were to suggest that earbuds disconnect me from the sounds of nature, I’d have to disagree. They don’t disconnect me from man-made sounds either.

Sometimes you’ll hear logging on the IAT.

The new building will include artist Jennifer Wen Ma's "Wings of Everchange 易之翼," a permanent, three-part art installation commissioned by the Department of Cultural Affairs’ (DCLA) Percent for Art program.

Working between Beijing and New York City, Ma has produced varied interdisciplinary media ranging from "cleansing walks," which appear like one-person funerary processions, to collections of plants coated in Chinese ink.

Designed by Grimshaw Architects, the new building retains architectural traces of the 1892 building, while expanding to include six community rooms, multipurpose areas, outdoor spaces, and several modern accommodations. The renovated building is expected to provide approximately 30% more public space than the original facility and will extend three floors higher.

Founded and constructed in 1892 as Public School 23, the building was repurposed into a community hub in the mid-1970s. After the fire devastated much of the building's structure in 2020, the five organizations operating there relocated to nearby venues. While MOCA had moved to its 215 Centre Street flagship in 2009, it retained the old gallery space at 70 Mulberry Street as an archival space and research library for the museum's 85,000-item collection, most of which was salvaged from the fire.

The central sculpture in the building's atrium will be modeled after the graceful brushstrokes of Chinese calligraphy and incorporates salvaged materials from the 2020 fire. Within the sculpture, glass orbs serve as time capsules dedicated to certain individuals or groups touched by 70 Mulberry Street. Ma also plans to launch a publicly accessible website and app with oral testimonies from 70 community members about the building. The third part of the installation extends to the historic spiral stairwell, where ink paintings on glass panels snake up several floors along the inner stair tower.

The New York City Public Design Commission unanimously approved Ma's design in January 2024 as part of the Percent for Art program, which mandates that 1% of eligible funds for city-backed construction projects be spent on public artworks.

Our Universe Is Held Together by Invisible Galactic Glue—And We Wouldn’t Exist Without It

📅 Nov 10, 2026  |  Category: Science  |  Read Source →

Its transformative emergence might have occurred within the very first seconds of time, physicists say.

Dark matter isn’t like other matter. It doesn’t interact with visible light or any other electromagnetic force. And yet, it seems to push around regular matter through its gravitational influence. Dark matter rules the universe, maybe holding galaxies together, but we still don’t know what it is.

A battery of cosmological probes has revealed clues to the presence—and influence—of dark matter in the universe: Stars orbit galactic centers far too quickly. Galaxies zip around clusters with excessive velocities. Massive objects bend the light passing by them with more gravitational force than we can account for with visible observations. And the history of the universe has revealed the incredibly speedy growth of gigantic structures.

The conclusion is that there’s something more to the universe than our traditional electromagnetic measurements can detect. Yet this thing simply doesn’t emit or absorb light. What could it be?

What we know is that it’s cold, heavy, and slow. Yet, new research suggests that it may have once been the complete opposite: hot, light, fast … and insignificant.

How do you turn dark matter from zero to hero? The answer lies in the strange and wonderful physics of superconductivity, which lets electricity flow with zero resistance. In a new paper, theoretical physicists Guanming Liang and Robert Caldwell from Dartmouth College outline a hypothetical scenario for flooding the universe with dark matter when it was mere seconds old.

For decades, cosmologists have been following one particular compelling idea to explain dark matter, known as WIMPs, for weakly interacting massive particles. These are hypothetical particles that only interact with the rest of the universe through gravity and the weak nuclear force (which rules subatomic particles’ behavior). But searches for WIMPs have so far come up empty.

To fill the gaps, theorists have been busy, generating dozens of new theories every year to unravel the mystery of dark matter. The vast majority of these ideas come from the land of high-energy physics, invoking this-or-that exotic process or super-theoretical particle that we might see someday in a collider. These massive machines smash high-energy subatomic particles together in the search for new particles.

But Liang and Caldwell took a different tack, turning instead toward condensed matter physics. This branch of physics makes major breakthroughs all the time, but without as much public fanfare as the high-energy work.

At a fundamental level, condensed matter physics is the study of stuff. It gives us an understanding of how everyday things work on subatomic levels—from why glass is transparent to how heat flows through new materials. And it’s also the study of everyday materials under extreme conditions, which leads to completely counterintuitive behaviors.

For example, take electrical resistance. Electrons flowing down a wire bump into each other, which saps energy out. This is why we can’t, for instance, have solar arrays in the desert that can pipe their electricity all around the country.

But if you cool some materials down to nearly absolute zero, the electrons bind up together in a new state of matter. And when they do that, all the resistance disappears, and electricity can flow uninterrupted. This is known as superconductivity, and it’s through superconductors that we’re able to harness tremendously large currents to drive technologies like MRI machines and maglev (magnetic levitation) trains.

In Liang and Caldwell’s model, dark matter starts out as a hot soup of fast-moving, massless particles in the extremely early universe. But as the universe expands and cools off, the dark matter particles pair together, the way electrons do in a superconductor. When they do that, the dark matter particles undergo a radical transformation, emerging on the other side with a brand-new set of properties. The pairs become slow-moving, heavy—and dark.

However, the model revealed an unusual quirk: that if the dark matter particles start out with even a tiny bit of mass, then not all of them bind up together as pairs. Most of them stay in the background, where they soak up all of spacetime. This behavior might provide an explanation for another mysterious ingredient in the cosmos, dark energy, which is responsible for causing the accelerated expansion of the universe.

So far Liang and Caldwell’s idea is just that: a guess as to how the universe might actually work. But it’s a testable one. The properties of these paired-up dark matter particles may leave behind a subtle signature in the appearance of the cosmic microwave background. That’s the light left over from when the universe cooled from a plasma to a neutral state, when it was around 380,000 years old.

To be fair, the idea is probably wrong. But that’s okay. We have no idea what dark matter is, and we need to flex every analytical and creative muscle we have to solve a puzzle that spans the entire universe. And we need to draw from as many sources of inspiration as possible, whether it’s high-energy physics, condensed matter physics—or even something else.

We never know when we’re going to be right. It’s only by searching in the dark that we’ll find out.

“What happens when children see these images? Neurological and psychological factors are affected, because they see body dimensions that are completely different from how they see themselves,” Milagros Jáuregui, a conservative senator from the Renovación Popular party, said in a speech on 26 October.

The sculptures are located in Parque de la Fertilidad (Fertility Park), a public space where in 2021 then-mayor Arturo Fernández of the Moche district began installing giant fibreglass reproductions of ceramic depictions of sexual acts to promote tourism.

Known as huacos eróticos, the much smaller original ceramics date from the 3rd to 8th century AD. No more than 30cm in height, they were placed in tombs as burial offerings. But the debate about their much larger versions in the park goes beyond political prudishness.

“It’s a complicated issue,” the Peruvian archaeologist Walter Alva tells The Art Newspaper. “There’s freedom to express or re-create themes from the past, but these ceramics were created to be placed as offerings to the dead, with a sense of revitalising life. One of the greatest archaeological discoveries from the Moche civilisation was that of the Lord of Sipán near the city of Chiclayo—a discovery Alva made in 1987. A 3rd-century monarch, the Lord of Sipán’s body was found covered with gold along with eight other people, a dog and two llamas and nearly 500 objects including ceramic vessels, ornaments and textiles.

The Moche have the largest number of erotic representations among pre-Hispanic civilisations. Why Prince William Is Reluctant to Become Head of the Commonwealth

📅 Nov 10, 2026  |  Category: Politics  |  Read Source →

Following King Charles’s successful nine-day tour to the Caribbean, the future of the Commonwealth has become a much debated subject. At last week’s Commonwealth Heads of Government Meeting (CHOGM) in Antigua and Barbuda, Charles, who was designated Head of the Commonwealth, a role he assumed after his late mother Queen Elizabeth, told assembled leaders he found the voluntary union of 56 nations to be a “source of enormous encouragement and pride.”

However, Buckingham Palace has made it clear this weekend that Charles will only serve as monarch in the Caribbean realms “for as long as they wish” and that the monarch is open to change. According to The Times, Charles is “fully open” to those realms removing him as head of state.

While Charles was in the Caribbean, there was ongoing debate about slave trade reparations, which the monarch addressed in his speech to CHOGM. Describing it as a “monstrous injustice” he expressed his “profound personal sorrow” but fell short of making a formal apology for Britain’s role in the slave trade. (Since King Charles is a ceremonial head of state, he is unable to apologize on behalf of Britain unless the government sanctions it.)

Amid calls for reparations, there are questions about the future of the Commonwealth and who its next head should be. In conversation with Vanity Fair, constitutional expert Ed Owens, author of After Elizabeth: Can the Monarchy Save Itself?, discusses what’s in store for the future.

This interview has been edited and condensed for clarity.

King Charles reacts near Antigua and Barbuda flags during a visit to Nelson's Dockyard, a historic naval base established in 1725, during his visit to Antigua and Barbuda on November 2, 2026 in St John's, Antigua and Barbuda.

Vanity Fair: Prince William has made it clear that he does not necessarily expect to follow his father as head of the Commonwealth, saying that the decision belongs to the Commonwealth itself.

Ed Owens: Prince William hinted after his difficult 2022 tour of Belize, the Bahamas, and Jamaica that he wasn’t focused on following his father as head of the Commonwealth. A couple of weeks ago The Times of London confirmed that the prince’s position was unchanged on this issue. Crucially, the position of head of the Commonwealth is not hereditary. King Charles got the role because his mother and predecessor, Queen Elizabeth II, actively lobbied Commonwealth heads of state to ensure that the role would pass to him when he became monarch, following her death. But it will not automatically transfer to William when Charles dies.

What is the Commonwealth and how significant is that statement?

The Commonwealth of Nations (as it’s officially known) is a voluntary association of 56 independent member states. Most of these member states were once colonies in the British empire. Decolonization began after World War II and most newly independent states—though no longer part of the empire—became part of the new Commonwealth. This new international body represented change but also continuity, enabling Britain to maintain a global (but mostly symbolic) presence at a time when its real geopolitical power was rapidly in retreat. The Commonwealth also provided a stage for the monarchy to continue to exercise an important international role. George VI was the last emperor and first Head of the Commonwealth. The latter role was invented by the British government to replace the former and allowed the monarch to maintain a semblance of global prestige while helping to facilitate the process of decolonization.

Although most member states have historical ties to Britain, any country can apply to join the Commonwealth—exemplified by recent members like Rwanda, Mozambique, Gabon, and Togo. Members commit to shared principles outlined in the Commonwealth charter, including democracy, human rights, the rule of law, and sustainable development. In reality, though, many member states have failed to live up to these principles, and the Commonwealth has, in recent years, felt morally directionless.

William’s reluctance to take on the mantle of Head of the Commonwealth isn’t that surprising: He and his advisers want to future-proof his reign. One way to do this is to identify potential problems in order to avoid them. The Commonwealth is one such potential problem, and William seems to have calculated that the headship of this organization likely represents more trouble than it is worth.

Does it represent a fundamental shift in the monarchy’s attitude toward the organization, or simply an acknowledgement that the old imperial relationship is no longer sustainable?

We have to remember that 15 members of the Commonwealth (including the UK) are also “realms”—i.e. their head of state is King Charles. I think it’s clear even to the current king that his position as monarch of the 14 realms beyond Britain is unsustainable. Eventually all 14 nations, and perhaps the UK too, will opt to become republics, cutting their ties with the crown. Those nations most likely to become republics soonest—owing to the fact that they have surging republican movements—are the Caribbean realms, two of which (the Bahamas and Antigua and Barbuda) King Charles visited during his recent tour to the Caribbean. Indeed, we can even interpret the tour as the king and his courtiers preparing the ground for this transition to republics. This is because, though former realms will no longer have as their head of state the incumbent monarch, they will almost certainly remain members of the wider Commonwealth.

What King Charles was trying to do with his latest tour was to inject energy and meaning into the idea of the Commonwealth, more than attempt to reinvigorate the personal bonds that connect him to his peoples in the Caribbean. In loudly acknowledging the injustices of the slave trade in which Britain was, for a long time, complicit, while also reminding his hosts that Britain was one of the first major powers to abolish and oppose slavery—the king has sought to address and ease concerns in ways that might enable the Commonwealth to function more cohesively in the future, irrespective of whether the UK’s monarch remains in post as head of the Commonwealth.

When Charles eventually leaves the throne, could the Commonwealth decide that it no longer needs a British monarch as its figurehead? What might replace that role? Will the Commonwealth continue?

I absolutely think [the] Commonwealth nations will look to replace the British monarch with a new figurehead. My sense is that many nations would already prefer to have a different kind of figurehead, for example a head who belongs to one of the 56 member states and is elected by member states for a set term. Alternatively, there could be some kind of “rolling” headship, whereby every member nation is invited to elect an official who will take a 12-month turn as head of the Commonwealth.

Whether or not the Commonwealth will continue is more difficult to say. Certainly one of the reasons it has survived until now is because of the energy and engagement of two British monarchs—Charles and Elizabeth II—who have viewed it as a potential force for good in the world. Without its connection to the British monarchy, it may lose what is left of its momentum. However, its survival also depends on wider geopolitical shifts: If individual governments within the Commonwealth view it as [a] useful arena for bringing together states who could benefit from closer association—be that economic, political, or military association—then it may continue long into the future.

There is an increasingly difficult conversation about Britain’s colonial past, slavery, and reparations. Charles has expressed personal sorrow over the slave trade, but the question of a formal apology remains politically and constitutionally complicated. How much freedom does the king actually have to address these issues, and could William take a different approach?

The king has very little freedom to apologize unless his government specifically sanctions and encourages such an apology. As the recent Caribbean tour made clear, I think Charles would prefer to strike a more nuanced line, reminding audiences that, despite the UK’s colonial past and its involvement in the horrors of slavery, Britain was one of the first major powers to abolish slavery and that it played an important role in bringing to an end the maritime trade in human chattel. Whether William takes a different approach will depend entirely on the UK government’s approach to formal apologies and reparations. My sense is that no government—at least not now or in the near-to-medium-term future—will agree to financial reparations, because historians, philosophers, and politicians are increasingly pushing back on such a solution, questioning why UK taxpayers (already under huge strain) should fork out huge sums for the wrongs committed by some of their ancestors more than two centuries ago.

What would Queen Elizabeth II make of this? She saw the Commonwealth as her father’s legacy and her second family.

I think she would probably be relatively relaxed, recognizing that times change and institutions have to evolve. Let’s not forget that as queen she oversaw many key alterations in the way both the monarchy and Commonwealth functioned through her long reign, as was required by shifts in politics, economics, culture, and social norms. While the Commonwealth was of emotional importance to her—not least for the way it connected her back to her father and predecessors—by the end of her reign it was already a shadow of what it once had been and she would have known that it was likely to continue on a trajectory of decline. William has decided that given the challenges and changes of the mid-20th century the monarchy and royal family’s future is likely to be stronger without the post-imperial baggage of the Commonwealth. I think his grandmother would have respected the way he is putting the family firm first in this instance.

Fernando Mendoza inherits a 4-5 Raiders team and NFL history offers two wildly different outcomes

In 2016, the Rams were 4-5 when they benched Case Keenum and handed the offense to No. 1 overall pick Jared Goff. He lost all seven of his starts, threw five touchdowns and seven interceptions, and LA finished 4-12. Jeff Fisher was fired with three games remaining, the Rams hired Sean McVay that offseason, and the rest is history.

Two years later, the Ravens were also 4-5 when Lamar Jackson, the final pick of the first round in 2018, replaced an injured Joe Flacco. He won six of his first seven starts, and Baltimore won the AFC North before losing to the Chargers in the wild-card round. Jackson threw just five touchdowns, but his ability to run transformed everything about the offense.

Same record. Same point in the season. Two completely different outcomes.

And now comes Fernando Mendoza, the No. 1 pick in April's draft, who inherits a 4-5 Raiders team after Las Vegas traded Kirk Cousins to Minnesota on Tuesday for a third-round pick. Mendoza will make his first start Sunday against the Seahawks, and while it's tempting to think nine weeks on the bench may have helped prepare him for what's next, history suggests it could be a little more complicated than that.

Since 2000, 148 quarterbacks have started at least one game as NFL rookies. Just 22 made their first start between Weeks 10 and 13, and their collective debuts were not pretty.

They completed just 53.8% of their passes, averaged 5.8 yards per attempt and threw interceptions on 5.3% of their dropbacks – the worst marks of any group. Only five of those 22 won their debuts, and their interception rate was more than 1.6 times that of rookies who started in Week 1.

How rookie QBs performed in their first career start, 2000-2025

Of course, circumstances matter. Some quarterbacks sat because they weren't ready. Others played because the starter got hurt or was ineffective. But the takeaway remains: Sitting for half a season doesn't guarantee a smoother transition to the top of the depth chart.

Five teams had winning records when they turned to a rookie in Weeks 10-13. They were a combined 30-19 before the change and went 10-20 afterward. The 17 teams with losing records fared slightly better when they installed a rookie under center, improving their winning percentage from 28.9% to 33.7% – though they still lost twice as often as they won.

Team performance before and after a rookie's first start, Weeks 10-13

Only three of those 22 teams made the playoffs. The 2011 Texans turned to T.J. Yates after injuries to Matt Schaub and Matt Leinart. The 2017 Bills benched Tyrod Taylor for Nathan Peterman despite sitting at 5-4. Peterman threw five interceptions in the first half of his debut, Taylor reclaimed the job at halftime, and Buffalo eventually made the playoffs with Taylor back under center.

Jackson was different. Baltimore initially needed him because Flacco was injured, but he played so well that they stuck with him even after Flacco was healthy. Obviously, that's a blueprint the Raiders would love to follow, but it's fair to say the organizational infrastructure isn't quite there yet.

And then there are the more immediate concerns for the Raiders rookie…

Mendoza's first three starts come against Seattle, Denver and Cleveland, which also happen to be three of the league's best defenses. The schedule gets less daunting after a Week 13 bye, though matchups against the Broncos and Chiefs make up two of the Raiders; final four games. So yeah.

There is a bigger issue: Mendoza could play well and still lose a bunch of games, and Vegas' first nine weeks help explain why.

Kirk Cousins wasn't the reason for all the losing when Vegas traded him. He had thrown 20 touchdowns and just eight interceptions, and the team was averaging 25.4 points per game. Their passing offense ranks fifth in yards per game and ninth in EPA per play, so Mendoza isn't walking into a no-win situation.

The problems lie everywhere else. Las Vegas ranks dead last in yards per carry (2.9), 31st in rushing yards per game (71.3) and 30th in rushing success rate. The defense hasn't been much better, allowing 35.7 points per game over the last six weeks, five of them losses.

That's a tough combination for any quarterback, future Hall of Famer or fresh face of the franchise. Kubiak's system can help, but even the best-designed offense needs a run game that provides some balance.

Back in June, I wrote that Mendoza might be the most NFL-ready quarterback in the class but had landed in the least quarterback-friendly situation. My rookie QB model had him completing 61.4% of his passes, averaging 6.6 yards per attempt with an 82.1 passer rating.

Which brings us back to Goff and Jackson.

They started their careers headed in opposite directions, yet both eventually became two of the NFL's best quarterbacks. Goff didn't reach his current level until Detroit surrounded him with a strong offensive line, dependable running game and playmakers (and early on, Ben Johnson). Baltimore built its offense around Jackson's unique abilities rather than asking him to become something he wasn't.

The Raiders already have their quarterback of the future. Mendoza has eight games to show what he can do, but whether he goes 0-8, 6-2 or somewhere in between won't tell us much about the quarterback he could become. His job is to prove he belongs. The organization's job is to make sure he has a chance to succeed.

Muhammed Damar is back in the German U21 national team after almost a year away. The 22-year-old attacking midfielder’s return comes at an important juncture in a career that has experienced both significant promise and frustrating setbacks over the past two seasons.

Speaking at Tuesday’s DFB U21 press conference, attended remotely by Get German Football News, Damar expressed his delight at rejoining Antonio Di Salvo’s squad ahead of the upcoming internationals against Belgium and Croatia. Damar spoke warmly of the welcome he received from his teammates and the continued support of Di Salvo throughout his absence.

The midfielder’s resurgence at VfL Wolfsburg has provided the foundation for his international comeback. Four goals and one assist across his last six league appearances have helped restore the attacking midfielder’s reputation following an extraordinarily difficult year at Hoffenheim.

Damar’s career has already taken several turns. The Berlin native joined Hoffenheim from Eintracht Frankfurt’s youth setup in 2022. After an unsuccessful loan spell at Hannover 96, he truly announced himself during the 2024/25 campaign at SV Elversberg.

Damar scored nine goals in 31 league appearances for the Saarland club, helping Elversberg reach the Bundesliga promotion play-off. His performances attracted considerable attention from top-flight clubs, including Borussia Dortmund and Stuttgart.

Hoffenheim responded by extending his contract until 2029, with Damar viewed as a potential successor to Bayern Munich-bound midfielder Tom Bischof. The anticipated breakthrough in Sinsheim never materialized.

As GGFN examined during the most recent summer transfer window, Damar struggled to establish himself amid fierce competition in Hoffenheim’s attacking ranks. Andrej Kramaric and Bazoumana Touré stood in his way, leaving the youngster with only two starts across 15 Bundesliga appearances last season.

For a player whose development had accelerated so impressively at Elversberg, the lack of regular football represented a considerable setback.

Damar eventually opted for another opportunity in the 2. Bundesliga. Relegated Wolfsburg secured his services in July, signing the attacking midfielder to a contract through 2031. The decision has already begun paying dividends.

The 22-year-old has started ten of Wolfsburg’s first eleven league matches under head coach Tobias Strobl. Primarily operating in an advanced midfield role, Damar has also featured centrally when required. More importantly, the regular minutes have allowed him to rediscover the attacking qualities that made him such an intriguing prospect at Elversberg.

It wasn’t an immediate turnaround. Damar failed to register a goal or assist in Wolfsburg’s opening five league fixtures, but his fortunes began changing in September. The first breakthrough came in Wolfsburg’s emphatic 5-1 victory over Darmstadt on September 18. Damar converted a Joakim Mæhle assist in the 67th minute to put his team 4-1 ahead. The goal marked the beginning of a productive run that continued into October.

In Wolfsburg’s extraordinary 4-4 draw against Nürnberg on October 10, Damar doubled his team’s advantage with a well-placed long-range effort in the 29th minute. He attempted five shots during the match, placing three on target.

One week later, Damar again made a decisive contribution in Wolfsburg’s 3-1 victory over fellow Bundesliga relegation sufferers Heidenheim. With his team defending a narrow 2-1 lead, Damar latched onto a Fabian Reese layoff outside the penalty area and unleashed an effort that deflected into the net in the 65th minute.

The midfielder was particularly active in the encounter, recording six shots, four of which were on target. He also covered 12 kilometres, more than any other Wolfsburg player, and subsequently received the club’s Player of the Match award following a supporters’ vote.

Damar’s recent performances have not been limited to goalscoring. In Wolfsburg’s 1-1 draw at Bochum on October 23, he registered the assist for Reese’s opening goal, switching play from the right half-space to the left side of the penalty area. Reese finished with an impressive volley.

Five days later, Damar supplied another assist in the DFB-Pokal against SC Freiburg. His sharply delivered 43rd-minute corner found Kento Shiogai at the near post, allowing the Japanese international to head Wolfsburg into a 2-1 lead. The performance earned Damar a rating of six in GGFN‘s firsthand match assessment, although Freiburg eventually prevailed 3-2 following two late Keisuke Goto goals.

Damar returned to the scoresheet in Wolfsburg’s subsequent 2-0 league victory over Osnabrück. Once again combining effectively with Reese, the attacking midfielder met his teammate’s cutback and guided a technically accomplished right-footed finish into the bottom corner in the 50th minute.

Damar’s four league goals and one assist across his last six appearances, supplemented by a cup assist, reflect a player who is once again influencing matches through shooting, combination play, and set-piece delivery.

Crucially, he is doing so while receiving the consistent opportunities that proved so elusive at Hoffenheim.

Interestingly, Damar revealed at Tuesday’s press conference that a return to Elversberg had also been discussed before his Wolfsburg move. Responding to a question from Kicker’s Michael Pfeiffer, the midfielder confirmed that he remained in contact with current Elversberg coach Vincent Wagner, whom he knew from their time together at Hoffenheim.

“I know Vincent Wagner from Hoffenheim’s U23,” Damar explained. “Whenever I wasn’t playing with the first team, I went down to the U23s. We’ve maintained a very good relationship. We exchanged messages, but in the end I decided on Wolfsburg.”

He nevertheless retained considerable affection for his former loan club.

“Elversberg is an excellent place for young players,” Damar said. “You receive enormous trust from everyone there and can play football freely, without pressure.”

His assessment was echoed by fellow press conference attendee Maurice Krattenmacher, who joined Elversberg from Bayern Munich in the summer of 2026 and earned a late call-up to the U21s ahead of the current break. The 21-year-old highlighted the club’s willingness to invest in youngsters and provide opportunities even when their initial performances fall short of expectations.

“As a young player, you get your chance there,” Krattenmacher explained at the press conference. “And even if you don’t quite make the most of that chance, you get a second one. The team also welcomes you very well. I think it’s the combination of trust and good coaches that makes the difference.”

His previous international performances had provided compelling evidence of his potential even while his club career remained frustratingly stagnant. GGFN repeatedly highlighted the youngster during Germany’s 2025 U21 European Championship qualifying campaign.

Our September tactical assessment praised Damar’s strong second-half performance against Albania and his goal in the subsequent 5-0 victory over Latvia. The midfielder again featured among our six standout performers from the October international break.

Despite Germany’s 3-2 defeat against Greece, Damar impressed with his work rate, attacking involvement, and goal. His contribution against Northern Ireland offered further evidence of his value to Di Salvo’s squad.

Financial institutions confront the complexities of scaling AI

📅 Nov 10, 2026  |  Category: Technology  |  Read Source →

AI in financial services is moving beyond the pilot phase as banks, capital markets firms, mortgage lenders and other organizations begin deploying the technology more broadly. The challenge is shifting toward managing AI responsibly at scale while meeting strict requirements for security, compliance and customer trust.

The AWS Financial Services Symposium highlighted that transition in May. As financial institutions expand their use of AI, they have opportunities to test new applications without committing to large-scale deployments, according to Scott Mullins, former general manager of AWS Worldwide Financial Services at Amazon Web Services Inc.

“You can spin this stuff up really quickly; you can experiment with it,” he said during the symposium. “You can show that it actually achieves the things that you want to achieve within specific policy guidelines and frameworks, and you can actually evaluate whether that governance is holding.”

This feature is part of SiliconANGLE Media’s ongoing coverage of the AWS Financial Services Symposium. (* Disclosure below.)

Moving AI from experimentation into production requires financial institutions to address a different set of challenges. Beyond demonstrating that the technology works, organizations must establish the governance and operational safeguards needed to support AI across regulated business processes, according to Paul Nashawaty, practice lead and principal analyst for application development at theCUBE Research.

“Our AppDev research shows that 92% of organizations now integrate AI into at least one stage of the software delivery lifecycle, yet only about one-third have established the governance, security, and operational maturity required for production-scale AI,” he said. “In banking, capital markets and insurance, the gap is even more pronounced because compliance, explainability, and customer trust are non-negotiable. The next phase of AI adoption will be defined less by model performance and more by platforms that embed policy controls, auditability and security into AI-enabled workflows while improving customer experiences and operational efficiency.”

Infosys Ltd. is addressing those requirements through its AI platform, which incorporates safeguards and controls intended to help financial institutions deploy AI while managing risk, according to Rajaram R.K., vice president and head of sales for financial services at Infosys.

“It has the securities [and] it has the guardrails. It has the token economics … all the capabilities that an organization would need,” he told theCUBE.

Financial institutions face stringent regulatory requirements, making security, auditability and recovery essential to their operations. As banks, insurers and capital markets firms expand their use of AI, those requirements take on additional importance, particularly when automated systems begin influencing business decisions. Despite these challenges, financial institutions are among the sectors leading the way in AI adoption.

“The organizations that treat AI as a regulated business capability, not simply a technology initiative, will be best positioned to accelerate innovation while maintaining resilience and meeting evolving regulatory expectations,” Nashawaty said.

Applying those established risk-management practices to AI requires organizations to consider how automated systems access data, make decisions and operate within existing policies. The challenge is extending governance and operational controls to AI-enabled workflows without undermining the efficiency and innovation those systems are intended to deliver.

Financial institutions are finding practical applications for AI in customer service and employee productivity. At New York Life Insurance Co., reducing routine manual work is giving employees more time to provide personalized service and respond proactively to customers’ needs, according to Kristina Welke, vice president at New York Life.

“We really felt there was a lot of opportunity to support them, remove the manual work they do every day, enable them to provide that consultative support, be proactive versus reactive,” she told theCUBE.

Fifth Third Bank is using conversational AI to improve customer interactions and reduce average call-handling time. The bank is using Amazon Connect to support its customer-service operations, according to Kevin Anderson, product manager on the AI transformation team at Fifth Third Bank.

“Amazon Connect really lays the foundation as it solves for not only messaging but voice as well, allows for AI and automation,” he explained.

For financial institutions, scaling AI depends in part on modernizing the infrastructure that supports data-intensive workloads. Cloud platforms can provide the flexibility to deploy new capabilities while maintaining access to existing systems, making modernization an important consideration as organizations expand their AI initiatives.

Mortgage lender PennyMac Financial Services recently expanded its agreement with Amazon Web Services to accelerate modernization of its proprietary mortgage servicing platform, Plaisse. The partnership also includes plans to deploy enterprise-grade AI capabilities and further develop the platform.

As financial institutions modernize their infrastructure, they also need ways to move and manage data without disrupting existing operations. NetApp Inc. is addressing those requirements through storage and data-management capabilities designed to support migration, resilience and performance in AWS environments, according to Jacob Lim, cloud solutions architect at NetApp.

“We create value for customers by making it simple to migrate and run their data in AWS by combining proven NetApp ONTAP capabilities, such as space-efficient snapshots, near-instant data cloning capabilities with minimal storage overhead and storage performance,” he told theCUBE. “Then, there is also the highly efficient data replication and ransomware detection engine natively built into the operating system directly. Scaling AI in financial services brings new challenges

As financial institutions incorporate AI into daily operations, managing the complexity of those deployments is becoming an increasingly important challenge. According to PagerDuty’s 2026 State of AI-First Operations report, 59% of surveyed banks were actively incorporating AI into their operations, while another 34% were discussing implementation. As adoption expands, institutions must determine how to govern these systems, maintain data quality and integrate AI into existing workflows.

“I think you’re going to see AI really become: How do we govern, how do we use [and] how do we make sure the data’s clean? How does it become [about] helping us be more efficient in what we’re doing in day-in and day-out operations?” Todd McNabb, chief revenue officer of PagerDuty Inc., told theCUBE.

Technology providers are responding to the demand for faster enterprise AI deployment. AWS’ recently announced $1 billion investment in forward-deployed engineering, for example, is intended to help customers develop and deploy agentic AI applications more quickly. For financial institutions, however, the measure of success will extend beyond deployment speed to how effectively AI can operate within existing systems, regulatory requirements and business processes.

Shopping for a snowboard can be overwhelming, especially as a beginner. We’re not going to dive too deep on snowboard tech here (you can check out our additional snowboard coverage here for that), but we want to quickly help you understand a few key concepts discussed in this guide.

“Beginner” is a broad and admittedly unhelpful phrase. If you’re a true first-timer or close to it, you should focus on the first four snowboards in this guide. The best beginner snowboards are on the softer side, making them more approachable and easier to learn the basics on. They’re also generally a little cheaper than the next four boards we’ve included in this guide, which are boards we recommend for more experienced beginners, those approaching intermediate status, or riders who are hellbent on progression or excited to explore a certain style of riding.

Snowboards come in all shapes and sizes, but they can be considered true twins, directional boards, or directional twins.

True Twins, like the Rossignol Ampage, have a symmetrical nose and tail, which look the same and have the same flex. This ensures that the board feels the same whether you’re riding regular or switch. Twins are popular with park riders, as riding switch is a keystone of freestyle snowboarding. True twins are also a sweet choice for beginners, as they make learning “falling leaf” down steeper slopes a piece of cake.

Directional snowboards, like the Jones Frontier 2.0, have a purpose-built nose and tail. They’re designed to be ridden primarily in one direction, with the nose pointing downhill. They often have bigger, floatier noses and shorter, stubbier tails, a combination that can supply stability at speed, buoyancy in deep snow, and landing prowess. Directional snowboards often have taper, which means the nose is wider than the tail, and a setback stance that is bumped toward the back of the board. Both setback and taper can contribute to float and stability.

The main downside of directional boards is that they don’t ride switch nearly as well, which explains why many freeriders and all-mountain riders prefer directional boards, but freestylers stick to twins.

Directional twins combine certain elements from twin boards and others from directional boards to create hybrids that perform across a variety of conditions. For instance, the Jones Rally Cat is a directional twin in the sense that it features a nose and tail that are exactly the same width, enabling it to ride switch well, like a twin. But the nose is longer than the tail, helping the Rally Cat to float in powder and tackle steeper terrain like a directional board.

When you lay a snowboard flat on the ground and look at it from the side, you’re getting a feel for its profile. Profile dictates much of a snowboard’s riding qualities, as it influences how you weight, flex, and engage the board’s sidecut on snow.

Cambered snowboards, like the Burton Good Company Camber, look like an upside-down “U” when you lay them flat on the ground. There’s a raised central section between your feet, and two points of contact with the ground toward the nose and tail. Camber provides grip when you’re carving on firm snow, reliability and edgehold in technical terrain, and power when you’re snapping ollies. For some beginners, camber can be a touch trickier to learn on, and  can feel catchier than rocker. However, camber also helps snowboarders learn fundamentals the right way. You can’t cheat on a camber snowboard, whereas a rocker board is more forgiving and can subsequently let snowboarders develop sloppy habits. For that reason, we mostly recommend camber-dominant shapes in this guide, like our top pick, the Salomon Pulse and Lotus.

Rocker is the opposite of camber. The “U” is right side up this time, as rockered boards have one central point of contact with the ground between the feet, and the nose and tail are raised off the ground. Rocker-dominant boards, like the Rossignol Ampage Vol. 2, are less catchy than their camber counterparts, and they’re generally more playful, easier to butter, and more buoyant. However, they’re also less stable and don’t ollie as well.

Just like directional twins combine aspects from twins and directional shapes in search of a balanced ride, hybrid profiles merge attributes of camber and rocker. For instance, the CAPiTA Outerspace Living pairs grippy camber underfoot with catch-free, floaty rocker in the nose and tail.

Now that you’ve narrowed in on the board you want, you face an equally important question: What size should you get? Sizing a snowboard correctly can make or break your season, but the truth is that there’s no perfect formula. Here are a few things to consider to make the best possible choice for you.

Even as a beginner, you can learn about your preferences from snowboards you’ve already ridden. For instance, if you rented a 155 and it felt too squirrely and unstable, you might want to size up a touch. If you demoed a 160 and it felt too beefy and you weren’t able to turn it, sizing down is a smart idea. Especially as you’re progressing from a true beginner towards intermediate status, it’s important to demo lots of snowboards, as it’ll help you develop your personal taste and your snowboard vocabulary.

Always pay close attention to specs provided by manufacturers, as many brands provide helpful sizing parameters, including ranges for rider weight, boot size, and height. Use this information as a potential starting point.

Between two sizes? If you’re a beginner or riding park, gravitate toward the smaller size, which are easier to turn and spin. If you’re getting more advanced or you’re riding powder frequently, consider the bigger size, which provides more float and stability.

Some brands won’t give you a range of rider heights, but they will give you a range of rider weights, as weight influences how a rider engages flex and how much a board will float. For example, there are skinny 6’3” riders who like 158s, and squat, powerful 5’8” riders who dig 160s.

If you have average-sized feet for your height and weight, you don’t need to worry too much about boot compatibility. But if you have big feet—say, you’re 5’9” and 150 pounds, but you have a size 11.5 boot—it’s important to consider wider snowboards like the Cardiff Lynx. Wide boards help riders with big feet avoid dragging their toes in the snow, which is at best annoying and at worst can cause avoidable crashes. When you scan those manufacturer-provided specs, pay attention to the width and, if possible, ideal boot size ranges. It’s also worth noting that certain snowboards, like the Never Summer Proto Type 3, are available in standard sizes, as well as wide sizes, which Never Summer denotes with an “X.”

3 Easy Hacks To Make Instant Mashed Potatoes WAY Better

📅 Nov 10, 2026  |  Category: Technology  |  Read Source →

You might prefer homemade mashed potatoes, but sometimes you just need a shortcut—and on days like that, grabbing the box is WAY easier. But while the back-of-the-box directions will yield just-fine results, a few easy hacks will give you much better results.

As a recipe developer and professional cook, I don’t often make instant mashed potatoes, but I was excited by the challenge of leveling them up—without adding a bunch of extra ingredients or steps that take the convenience out of this convenience food. So I tried making instant mashed potatoes every way I could think of (including the way the box says!). In the end, I found three tricks that, while super simple, massively improve that final bowl of mashed potatoes.

Here are three ways to instantly upgrade instant mashed potatoes.

Most boxes tell you to rehydrate instant mashed potato flakes in hot water enriched with a little butter and a few tablespoons of milk—but I’m going all in on the milk here. The extra dairy really fills out the flavor of the mashed potato and makes it creamier—especially if you’re using a higher-fat milk, like whole or 2%.

When swapping milk for water, it’s best to increase the liquid amount just slightly. For some reason (totally scientific, I’m sure!), the potato flakes require more milk than water to hydrate properly. I recommend 2 extra tablespoons for every half cup of instant mashed potatoes.

Also, add the extra milk the box typically calls for. If you leave it out, the potatoes will be dry. When I was testing, I found it didn’t really matter when that second amount of milk went into the pan (at the beginning versus just before the potatoes), but some boxes emphasize putting it in cold just before adding the potatoes—so if you want to do that to make you feel safer, be my guest!

All the instant mashed potatoes I made lacked seasoning—until I doubled the salt. Then they were perfect. Now here’s the thing: I was testing with Diamond Crystal kosher salt, which is less salty by volume than table salt or Morton’s kosher. The back of the instant mashed potato box didn’t specify what type of salt they used, so if they tested with a fine salt or Morton’s kosher, maybe ¼ teaspoon was the perfect amount. But in my kitchen with Diamond Crystal, it was woefully underseasoned.

Maybe you’re nervous about oversalting and don’t want to double or even slightly increase the salt right away. But regardless, I’m begging you: Taste those potatoes before you serve them and don’t feel bad if you have to add another hefty pinch.

You might assume that mashed potatoes should be made in a pot—I definitely did. But the fluffiest, creamiest instant potatoes I made in this whole testing process came from a wide, high-sided sauté pan. The reason for this? Absolute science.

When adding the instant potato flakes to the hot liquid, the goal is to distribute them as evenly as possible without working them too much. Yes, the back of the box says to “stir” the potatoes in, but in testing, I quickly discovered that even a few strokes can quickly lead to gummy potatoes.

Here’s where the pan size comes in. Using a wide pan increases the liquid's surface area, so you can sprinkle the potatoes evenly over the top and pat them down into the liquid instead of stirring. From there, let them stand until they’ve absorbed the liquid, then give them a few stirs. Trust me: They’ll be way fluffier because you messed with them less!

When would aliens contact Earth? Astronomers test a new idea

📅 Nov 10, 2026  |  Category: Other  |  Read Source →

Astronomers are searching for alien signals at a moving point opposite the Sun, testing a strategy that could help distant civilizations make contact.

Searching for alien signals sounds like a question of which star to aim a telescope at. It’s also a question of when to listen, because a civilization sending a focused radio beam toward Earth might transmit only at selected times.

For the first time, astronomers have specifically searched a moving point in the sky that could offer a shared cue for when to transmit and listen. They found no evidence of extraterrestrial technology.

Sofia Sheikh of the SETI Institute and Eleanor Hort of the University of New Mexico led the search, which used the Allen Telescope Array in Hat Creek, California.

Three nights of pilot observations in the summer of 2023 turned up 1.9 million radio signals, and all of them could be explained by human technology.

Two people who agree to meet in a city but forget to pick a time and place still have a decent chance of finding each other.

Each one picks the landmark the other is most likely to pick. Game theorists call that shared choice a Schelling point.

The team applied the same logic to a distant transmitter. From some directions in the galaxy, an observer would see Earth cross the face of the Sun once a year.

That crossing tells them a planet exists and how long its year is. It also shows the planet orbits at a distance where water can stay liquid.

Halfway through the crossing, Earth lies exactly between the transmitter and the Sun.

Seen from Earth, the transmitter would be in the direction directly opposite the Sun, a spot astronomers call the anti-solar point.

A sender could beam a signal toward Earth at that alignment, while astronomers on Earth listened toward the anti-solar point, without either side arranging contact beforehand.

“The challenge in SETI isn’t simply deciding where to point a telescope,” Sheikh said. “It’s figuring out where and when another civilization might choose to transmit.”

The idea is not new: a 1982 paper proposed it for Jupiter’s crossings, and a 2003 paper argued Earth’s were the better bet.

Yet by 2020, the Breakthrough Listen archive held not a single pointing within half a degree of the anti-solar point.

Two large radio surveys of the 1990s likely spent about 0.0004% of their time there, by accident.

The spot never stays put. As Earth moves around the Sun, the anti-solar point slides along the sky against the background stars, so the telescope has to follow it night after night.

The survey plans repeated observations two to three nights a week over about four years to build coverage along Earth’s orbit.

For the pilot, the team pointed 20 of the array’s 42 dishes at the anti-solar point for about 17 hours over three nights. The scans ran five minutes each and added up to 32 terabytes of data.

They listened between 1.06 and 2.38 gigahertz, a band that includes the radio frequency of hydrogen that early searchers once favored.

Every scan also recorded a second patch of sky nearby.

A signal from a distant point source should show up strongly in the target beam and faintly in the other. Interference from a satellite or a phone tower tends to appear in both.

The two-beam comparison alone removed 1.3 million of the 1.9 million signals. The team then plotted the most promising 2,114 and inspected each one by eye.

None of them looked like a deliberate alien signal.

Most were narrow and barely shifting in frequency, the signature of ground-based transmitters, and the few that drifted lined up with known sources of human interference, including satellite links.

A search that finds nothing still says something, because the old Arecibo planetary radar sent out a tight beam with an effective power of roughly 20 trillion watts.

The pilot was sensitive enough to catch a transmitter that strong from 44 to 124 light-years away.

The exact reach depends on where the signal fell in the beam and how fast its frequency drifted.

The pilot sets the first limit of any kind on alien signals timed to the anti-solar point. The limit applies to a narrow strip, though.

The telescope’s beam spans only about 5% of the width of the zone from which Earth’s crossings are visible. A transmitter slightly above or below that line would have been missed.

The full survey began after the pilot, two to three nights a week at higher frequencies chosen to dodge the worst interference. It has already logged more than 121 nights.

The team plans to report the first year of data in a later paper.

A detection would need a lot to be true: a civilization within reach, one that has noticed Earth, and one that reasons about meeting points the way people do.

The team doesn’t assume any of that; the search is a way to test it. It also assumes the sender has accounted for how long light takes to cross the gap, so the signal arrives when Earth expects it.

Whether anyone is transmitting at the anti-solar point is still an open question, and three nights can’t settle it.

The multiyear survey will test the idea across a much broader stretch of sky.

The full study was published in the journal The Astronomical Journal.

Zendesk is changing how businesses pay for its AI, charging them for problems solved rather than for the number of people using the software. The customer service company announced the change on Tuesday at its AI Summit in San Francisco, as part of a new Outcome AI Platform.

Under the new plans, customers set an ‘Outcome Budget’ and pay for each eligible issue the AI resolves or task it completes. Zendesk checks each result for quality and completeness, so customers can see what counts towards their budget. As a result, businesses can start small and spend more as the AI takes on more work.

Zendesk has backed this model before. Earlier this year, it argued alongside Sierra that AI agents should be paid per result, not per seat, and OpenAI has started trying a similar approach with some customers.

Tapan Patel, a research director at IDC, said the change reflects how business buyers now want to pay for AI. Linking cost to verified results, he added, makes it clearer what customers get for their money.

The platform is also built for a world where people send their own AI assistants to deal with companies. To help with that, Zendesk is launching the Open Service Directory, a public list where brands can register their official support channels. AI assistants can then use it to find verified help, even for brands that do not use Zendesk.

Brands control what they share and when a human must step in. The directory does not access private customer data or take any action itself. Early members include Betterment, ElevenLabs and Telekom Payment.

Meanwhile, a tool called Zendesk Bridge lets businesses connect AI agents and apps of their choice, such as ChatGPT, to Zendesk’s systems. Setting up a connection starts with a name, which is kept for audit logs, and a plain description of what the outside agent should and should not do.

Administrators then choose exactly what each agent may do, such as reading, creating, answering, updating or merging tickets. An assistant called Admin Copilot suggests which tools to switch on, based on the description.

Every action then passes through Bridge, which checks permissions and company rules and asks for human approval where needed. An observability page shows how many requests came from AI agents and how many from people, which ones were blocked and why. It also includes a kill switch. Bridge is in early access, and the directory is launching soon.

“People don’t think about which channels, systems, or departments they need to navigate to interact with a business,” said Zendesk chief executive Tom Eggemeier.

Other new tools, now generally available, help teams build and improve their AI agents. AI Agent Launchpad studies past customer conversations and suggests where AI could take over. In Zendesk’s demo for a scooter rental firm, it proposes a step-by-step process for rides that will not end, using a connected billing system such as Stripe.

Similarly, Agentic Analytics lets managers ask questions about their data in plain language, such as how many tickets are still open. They can then see whether changes are cutting repeat contacts.

The launch reflects changing habits, according to a Zendesk survey. It found that 52% of consumers are comfortable relying on personal AI assistants for everyday tasks. Even so, 84% said human help should always be available.

The announcement follows Zendesk’s purchase of Forethought, its biggest deal in two decades, as it builds out its AI agents.
